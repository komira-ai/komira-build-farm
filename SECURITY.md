# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub security
advisories. Do not open a public issue, discussion, or pull request.

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the problem, the affected component (`kbf-server`, `kbf-daemon`, or
   another crate), the version or commit, and the steps to reproduce it.

GitHub's guide to this flow is
[Privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

The maintainers will acknowledge the report, work on a fix in a private
advisory, and credit you in the published advisory unless you ask otherwise.

## Supported versions

kbf is in early development and has no stable release yet. Fixes land on the
`main` branch.
